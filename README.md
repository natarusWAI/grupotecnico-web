# Web de Grupo Técnico

Reparación de lavarropas y heladeras a domicilio · Montevideo, Ciudad de la Costa y La Paz.

## Arrancar
1. Instalá [Node.js 24](https://nodejs.org) y [Claude Code](https://claude.com/claude-code).
2. En esta carpeta: `npm install` y `npm run dev` → abrí http://localhost:4321
3. Abrí Claude Code en la carpeta (`claude`) y seguí `docs/PLAN.md` desde la Fase 0.
